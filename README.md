# Portfolio Gateway Landing Page

A sleek and modern single-page landing website built with **HTML**, **Tailwind CSS**, and a little JavaScript.

This page serves as a simple portfolio gateway with a featured image and a call-to-action button that redirects visitors directly to my portfolio website.

## Live Portfolio

Visit my portfolio here:

https://frankstack.com.ng

## Features

- Minimal black and white UI
- Fully responsive on all devices
- Centered hero layout
- Featured image section
- CTA button: **VISIT MY PORTFOLIO**
- Smooth animations
- Floating image effect
- Hover interactions
- Soft glow and glassmorphism styling
- Animated background effects
- Footer branding

## How It Works

1. User lands on the page
2. Sees centered image and CTA button
3. Clicks **VISIT MY PORTFOLIO**
4. Redirects to:

```bash
https://frankstack.com.ng
```

## Installation

Clone this repository:

```bash
git clone https://github.com/yourusername/portfolio-gateway.git
```

Open project folder:

```bash
cd portfolio-gateway
```

Run locally by opening:

```bash
index.html
```

or use VS Code Live Server.

## Customization

You can easily edit:

### Change portfolio link

Inside the button script:

```javascript
window.location.href = "https://frankstack.com.ng";
```

### Change featured image

Replace image source inside HTML:

```html
<img src="your-image.jpg" alt="Portfolio Preview">
```

### Change colors

Edit Tailwind classes:

- `bg-black`
- `text-white`
- `border-white`
